# Age Encryption Plugin

A plugin for Obsidian that provides [age-based](https://github.com/FiloSottile/age) encryption for your notes.

> [!CAUTION]
> **This plugin comes with NO WARRANTY and NO RESPONSIBILITY for any data loss or security breaches, use at your own risk**

![](./docs/showcase.gif)

## Features
- Encrypt whole file or selected text using age encryption
- View and edit decrypted content in memory without writing to disk
- Compatible with age CLI tool for external decryption
- Hints can be added to encrypted content

## Usage
Call `Encrypt Selection` command to encrypt selected text or `Encrypt File` to encrypt the entire file from the command palette.

## Security Notes
- Decrypted content is only held in memory
- No automatic writing of decrypted content to disk
- Makes symmetric encryption with a given passphrase, if you lose your passphrase, you lose your data FOREVER
- Based on your vault sync method, your secrets may get synced before you can decrypt them
- Regular backups of your notes are recommended
- This protects selected notes or blocks. It is not a replacement for full-disk or vault-level encryption

### Choosing a passphrase
Encryption uses a passphrase run through scrypt, which slows down guessing but cannot save a weak passphrase. Anyone who gets a copy of your encrypted note can try guesses offline, forever.
- Use at least 20 random characters, or 5+ random words, generated by a password manager. Do not reuse a passphrase from anywhere else
- Store it in your password manager, and keep an offline copy of it too. There is no recovery if it is lost
- A long random passphrase is as strong as a private key would be, as long as the place you keep it is secure

### Session passphrase caching
"Remember for this session" is **on by default** in the passphrase dialog. While on, the plaintext passphrase stays in memory (keyed by the encrypted block) until the plugin is unloaded or Obsidian closes, so you are not asked again for that block. Turn the toggle off if you share your machine or leave Obsidian open and unlocked.

### Plaintext left behind from before encryption
Encrypting a note replaces it on disk, but earlier plaintext can survive in other places. Encrypt **before** the first sync or commit where you can, and check these:
- Obsidian's **File Recovery** core plugin snapshots (consider disabling it, or clearing snapshots, for sensitive notes)
- **Git history**, if the vault is a repository (earlier commits keep the plaintext)
- **Sync history**, such as Syncthing versions, iCloud/Dropbox version history, and Obsidian Sync versions
- **Backups** such as Time Machine, and editor undo history in an open note
- Anything you copied elsewhere, such as the clipboard or other apps

### What is not encrypted
- File names, links, tags, and the hint text are stored in plain text
- With "Exclude frontmatter from encryption" on (the default), the YAML frontmatter stays in plain text too
- "Save as plain text" writes the decrypted content back into the note on disk

### Saving edited blocks
When you edit a decrypted block and choose **Save encrypted** or **Save as plain text**, the plugin finds the block in the note by its exact text. If the note changed in the meantime, or the block cannot be found exactly once (for example it sits inside a list item or quote), it shows a notice and leaves the note untouched. Reopen the note and try again.

## Manual Decryption
Encrypted content is stored in code blocks with language set to `age`. For example:
```age
-----BEGIN AGE ENCRYPTED FILE-----
YWdlLWVuY3J5cHRpb24ub3JnL3YxCi0+IHNjcnlwdCBrUWE0cmIxOFA3NUNXK3d1
V25pT1Z3IDE4ClBaMFY5NWc3bjZIMUxSNHRYSm9FUHMxamdsWjJ3UlhPZjM0R1pm
WFEzOEkKLS0tIHkwaFZNbmQybndaa2dxMkpxdUpOR01uZUQwK21oaSszai9hWnB3
ejJHaW8KxIr7k/vxvgqX0Dqun83t1yyupFW4JOYLzS9uwRSo5OxhCqf88SvxXbs=
-----END AGE ENCRYPTED FILE-----
```
You can always save this to a file and decrypt your content using the age CLI tool:
```bash
# Install age CLI tool first
age -d secret.age
```
The block format is standard age ASCII armor, so it works in both directions: you can also encrypt with `age -p -a` and paste the armored output into an `age` code block.
